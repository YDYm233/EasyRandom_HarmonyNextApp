# 转盘页面 — 用户使用说明

---

## 一、页面概览

打开转盘页面，你面对的是一个三区域纵向布局的卡片式界面：

| 区域 | 内容 |
|------|------|
| **顶部栏** | 左箭头（上一个） / 转盘名称 / 右箭头（下一个） |
| **中央大区** | 彩色扇形转盘 + 可切换的指针遮罩 |
| **底部操作栏** | 📌收藏 / **开始**按钮 / ➕管理 |

整个卡片采用 **7:9** 比例约束，小屏设备自动放大，大屏设备缩小，保证视觉舒适。

---

## 二、核心功能

### 🎯 1. 转盘轮播与浏览

通过**左右滑动**或点击顶栏 **← → 按钮**在不同转盘间切换。首次打开已内置 8 个常用转盘，覆盖多种生活场景。

| # | 转盘名 | 场景 |
|---|--------|------|
| 1 | 吃什么？ | 日常选择困难 |
| 2 | 随机颜色 | 设计 / 搭配参考 |
| 3 | 抽奖 | 活动 / 游戏 |
| 4 | 幸运嘉宾 | 抽人 / 点名 |
| 5 | 真心话大冒险 | 聚会游戏 |
| 6 | 今天穿什么 | 穿搭决策 |
| 7 | 周末去哪 | 出行安排 |
| 8 | 下午茶 | 饮食选择 |

切换时顶部标题即时更新，轮播支持循环无限滚动。

---

### 🎰 2. 转盘抽选（核心功能）

点击底部 **「开始」** 按钮后：

1. 转盘以平滑动画旋转——随机角度 + **18 圈**完整旋转（约 1.6 秒）
2. 按钮切换为旋转动画，视觉上反馈"抽选中"
3. 动画结束后，指针（如果开启）所指向的扇形区域即为**抽选结果**

本质是"把决策交给随机"——无需纠结，一键定夺。

---

### 📍 3. 虚实指针切换

**点击转盘区域**即可切换指针的显示或隐藏：

- **指针 ON**：类似传统转盘的压针，结果一目了然
- **指针 OFF**：纯粹欣赏彩色扇形图案，避免遮挡文字

初始状态为开启，用户可自主选择。

---

### ❤️ 4. 收藏转盘

底部 📌 按钮标记当前转盘为"收藏"：

- 未收藏：图标显示品牌色
- 已收藏：图标变白色，按钮底色高亮

快速标记常用转盘，类似"置顶"或"书签"。再次点击取消收藏。

---

### ➕ 5. 转盘管理

底部 **「+」按钮**唤起半模态管理面板，内嵌完整的管理功能：

#### 5a. 转盘列表
- 每个转盘以卡片展示：颜色指示点 + 名称 + 选项数量 + 箭头
- 点击任一卡片进入详情编辑页
- 空列表时显示"暂无转盘"提示

#### 5b. 新建转盘
- 底部 **「新建转盘」**按钮一键创建（默认包含 2 个选项）
- 创建后**自动进入编辑页**，无需二次操作

#### 5c. 编辑转盘详情
- ✏️ **修改名称**：TextInput 直接输入
- 🗑️ **删除转盘**：点击垃圾桶图标，弹出确认对话框，防误触
- 👁️ **实时预览**：顶部小转盘随编辑实时更新
- 🎨 **修改颜色**：点击色块弹出颜色选择器
- 📝 **编辑选项名称**：TextInput 直接改
- ⚖️ **调整权重**：数字输入，控制每个选项的中选概率
- ➕ **添加选项**：列表底部加号按钮
- 👈 **滑动删除选项**：左滑露出红色删除按钮，最少保留 2 个选项

---

### 💾 6. 自动保存

所有修改**无需手动保存**——改名称、改颜色、改文字、改权重、增删选项或转盘，均自动持久化到设备本地。下次打开 App，数据完好如初。

编辑场景采用双模式持久化策略：

- **编辑属性**（颜色/名称/权重）→ 静默写磁盘 + 仅刷新预览轮盘，不打断 TextInput 输入
- **增删结构**（添加/删除选项或转盘）→ 深拷贝推送 AppStorage，驱动全页面刷新

## 三、体验设计亮点

| 维度 | 说明 |
|------|------|
| **即时反馈** | 按钮有点击缩放动效，旋转有流畅加速-减速动画，Loading 态有旋转指示器 |
| **防误操作** | 删除转盘有二次确认、删除选项区分滑动/点击动作、选项至少保留 2 个 |
| **视觉一致** | 转盘扇形色彩鲜明、卡片圆角统一（12px）、品牌色贯穿（#007AFF） |
| **自适应** | breakpoint 系统按设备尺寸（sm / md / lg）自动缩放卡片 |
| **上手即用** | 首次安装预置 8 个实用转盘，无需任何配置即可体验 |
| **导航清晰** | 管理面板内嵌 Navigation 组件，管理 → 编辑 → 返回路径一清二楚 |
| **容错健壮** | 转盘被外部删除后，编辑页显示"转盘不存在"提示而非白屏/崩溃 |

## 四、一句话总结

> **开箱即用、所见即所得的随机决策工具**，覆盖选择困难（吃啥/去哪）、聚会游戏（真心话/抽奖）、日常搭配（穿啥/喝啥）等多种场景，提供零门槛个性化编辑，所有改动自动保存、无需操心。

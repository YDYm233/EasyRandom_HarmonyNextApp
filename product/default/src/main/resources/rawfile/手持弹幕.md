# 📋 手持弹幕功能 —— 完整规划方案

## 一、功能概述

**手持弹幕**是实用工具类应用的典型场景。用户在演唱会现场、好友生日派对、体育赛事等场景中，可通过手机屏幕全屏展示滚动字幕，实现应援口号、祝福语等信息的展示。

从 HarmonyOS 官方示例 **"LED滚动字幕"** 中得到启发，核心能力包括：
- 全屏沉浸式显示
- 文字跑马灯滚动效果
- 可自定义文字内容、字体大小、颜色、背景色、滚动速度等

### 4.2 核心交互流程

1. **设置页** (`TextMarqueePage`)：用户输入弹幕内容、调节字号、选颜色等
2. 点击「显示弹幕」→ 通过 `Navigation.pushPathByName` 携带 `MarqueeConfig` 参数跳转
3. **展示页** (`MarqueeDisplayPage`)：接收参数，强制横屏，全屏显示滚动弹幕
4. 点击屏幕可显示/隐藏返回按钮
5. 按返回键回到设置页

## 五、实现技术方案

### 5.1 设置页 - 预览区跑马灯

使用 **Text + TextOverflow.MARQUEE** 实现（API 18+ 推荐方式）：

```typescript
// 预览区 - 文字超长时自动跑马灯
Text(this.config.content || '请输入弹幕内容')
  .textOverflow({ overflow: TextOverflow.MARQUEE })
  .marqueeOptions({
    start: true,
    step: this.config.scrollSpeed,
    loop: -1,
    fromStart: this.config.direction === 'left'
  })
  .fontSize(this.config.fontSize / 1.8) // 预览区等比缩小
  .fontColor(this.config.fontColor)
  .fontWeight(this.config.fontWeight)
  .maxLines(1)
```

**备选方案**：如果 TextOverflow.MARQUEE 效果不满足需求，可使用官方 **Marquee 组件**：

```typescript
Marquee({
  start: this.config.isScrolling,
  step: this.config.scrollSpeed,
  loop: this.config.loop,
  fromStart: this.config.direction === 'left',
  src: this.config.content
})
  .fontColor(this.config.fontColor)
  .fontSize(this.config.fontSize)
  .fontWeight(this.config.fontWeight)
```

### 5.2 展示页 - 全屏弹幕

使用 **Marquee 组件** 实现全屏滚动，关键技术点：

1. **强制横屏**：
```typescript
// NavDestination 上设置
.preferredOrientation(window.Orientation.LANDSCAPE)
```

2. **沉浸式全屏**（可选，API 20+）：
```typescript
// 隐藏状态栏和导航栏
windowClass.setWindowLayoutFullScreen(true);
```

3. **点击切换控制栏显隐**：
```typescript
@State isControlVisible: boolean = false;

.onClick(() => {
  this.isControlVisible = !this.isControlVisible;
})
```

4. **超短文本补全**：Marquee 仅当文本宽度 ≥ 组件宽度时才滚动，短文本需补空格：
```typescript
normalizeContent(content: string, screenWidth: number): string {
  // 如果文本太短，用空格补全以确保滚动
  if (content.length * fontSize < screenWidth) {
    const spacesNeeded = Math.ceil(screenWidth / fontSize) + 10;
    return content + ' '.repeat(spacesNeeded) + content;
  }
  return content;
}
```

### 5.3 颜色选择器

使用 Grid 布局预设色板：

```typescript
@Builder
ColorGrid(colors: string[], selectedColor: string, onSelect: (color: string) => void) {
  Grid() {
    ForEach(colors, (color: string) => {
      GridItem() {
        Row()
          .width(36).height(36)
          .borderRadius(18)
          .backgroundColor(color)
          .border({
            width: color === selectedColor ? 3 : 0,
            color: '#007DFF'
          })
          .onClick(() => onSelect(color))
      }
    })
  }
  .columnsTemplate('1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr')
  .columnsGap(8)
  .rowsGap(8)
}
```

## 七、关键技术决策

| 决策项 | 采用方案 | 理由 |
|--------|---------|------|
| 跑马灯实现 | **Marquee 组件** | 系统原生支持，性能优化好，API 完善 |
| 页面架构 | **Navigation + NavPathStack** | Stage 模型推荐，支持参数传递 |
| 横屏实现 | **NavDestination.preferredOrientation** | 声明式，自动管理生命周期 |
| 状态管理 | **@State / @Prop** | 轻量级，适合页面级配置传递 |
| 颜色选择 | 预设 Grid 色板 | 简单直观，无需引入第三方库 |
| 短文本处理 | 空格补全 | 确保 Marquee 始终滚动，体验一致 |

# 随易 EasyRandom

> 随易是是一个面向生活的工具箱。
>
> 通过随机算法帮助我们做一些简单的决定，
> 例如：抽签、丢硬币、随机数等
>
> 提供一些有趣实用的功能，
> 例如:真心话大冒险、转盘、掷骰子等
>
> 注意！本app的结果完全由随机算法随机而来，不会偏向好的结果，也请勿过渡相信随机结果。

## 项目结构

```

│  ├──constants                              //公共常量

│  ├──defaultformability                     //卡片Ability
│  └──widgets                                //卡片组件
└──product/default/src/main/resources        // 资源文件目录
```

### SDK Import 路径修正（v3.4 实测验证）

编译过程中发现所有 `@kit.ArkUI` import 路径在 SDK 中实际不匹配，通过直接读取 SDK 中的 .d.ts 文件逐一确认：

| 组件/模块 | 错误写法（文档 v3.3） | 正确写法（v3.4 实测） |
|----------|---------------------|---------------------|
| ArcSwiperController, ArcDotIndicator, ArcDirection | `@kit.ArkUI` | `@ohos.arkui.ArcSwiper` |
| ArcButtonPosition | `@kit.ArkUI` | `@ohos.arkui.advanced.ArcButton` |
| display | `@kit.ArkUI` (存疑) | `@ohos.display` (手机端已确认) |
| CrownSensitivity | 需要 import | 全局枚举，API 18+ 自动可用 |
| ArcSwiper 组件名 | 需要 import | 导入 `@ohos.arkui.ArcSwiper` 后自动注册 |

**关键发现**：Arc 组件名（如 ArcSwiper、ArcButton）不需要显式 import，只需要 import 模块中的类型（controller/attribute/enum），组件名会自动注册到全局作用域。

**构建配置修正历程**：
1. `build-profile.json5` 取消 wearable 模块注释 → 缺逗号 JSON5 语法错误
2. `applyToProducts: []` → minItems 不允许空数组，移除整个 targets 块
3. `compatibleSdkVersion: "5.0.2(18)"` → 平台号与 API 不匹配，改为 `"5.1.0(18)"`（SDK 中 API 18 = 5.1.0）
4. wearable 模块级 `build-profile.json5` 不能设 `compatibleSdkVersion`（不在 schema 允许字段中），只能通过根 product 级别设置

### ArcSwiper API 修正（v3.5 SDK 实测）

编译发现 Index.ets 中 ArcSwiper/ArcDotIndicator 的实际 API 与之前假设不符。通过读取 SDK 真实 .d.ts 声明文件确认：

| 问题 | 之前（v3.4） | 修正后（v3.5） |
|------|------------|-------------|
| Import 路径 | `@ohos.arkui.ArcSwiper` | `@kit.ArkUI`（SDK kit 入口 re-export，更规范） |
| ArcDotIndicator 颜色 | `.color()` / `.selectedColor()` | `.itemColor()` / `.selectedItemColor()` |
| ArcDotIndicator 阴影 | `.itemShadow(true)` | **不存在此方法**（SDK 中无 itemShadow） |
| ArcSwiper 构造函数 | `{ controller, indicator }` (对象参数) | **仅 `controller`** (可选参数，indicator 通过 `.indicator()` 链式设置) |
| ArcSwiperAttribute | 需要手动 import | `@kit.ArkUI` 已 re-export，自动可用 |

**根本原因**：SDK 声明文件中 `ArcSwiper` 的构造函数签名是 `(controller?: ArcSwiperController): ArcSwiperAttribute`，只接受 controller 参数。indicator 等属性通过 `ArcSwiperAttribute` 的 `.indicator()` 方法设置。

### build-profile.json5 修正

按照 wearable-plan.md v3.6 方案，修正了构建配置：

**修改1：添加 wearable product**
在 `products` 数组中添加 wearable product，独立设置 `compatibleSdkVersion: "5.1.0(18)"`：
```json5
{
  "name": "wearable",
  "signingConfig": "default",
  "compatibleSdkVersion": "5.1.0(18)",
  "runtimeOS": "HarmonyOS",
  "targetSdkVersion": "6.1.0(23)"
}
```

**修改2：为 wearable 模块添加 targets 绑定**
在 `modules` 数组的 wearable 模块中添加 `targets` 字段，显式绑定到 wearable product：
```json5
{
  "name": "wearable",
  "srcPath": "./product/wearable",
  "targets": [
    {
      "name": "wearable",
      "applyToProducts": ["wearable"]
    }
  ]
}
```

**架构说明**：
- `products` 数组：定义构建产物，每个 product 可独立设置 `compatibleSdkVersion`
- `modules` 数组：定义模块，`targets` 字段指定该模块绑定到哪些 product
- 这样 watch 端可以使用 API 18+ 的 ArcSwiper/ArcButton/ScreenShape，而手机端保持 API 13+
